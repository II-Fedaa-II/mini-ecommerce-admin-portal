# Mini E-Commerce — Admin Portal

React + TypeScript + Vite admin control panel for the Mini E-Commerce assessment project.

Product management and role-based access control (RBAC), served as an independent frontend against the shared backend.

## Related repos
- [mini-ecommerce-backend](https://github.com/II-Fedaa-II/mini-ecommerce-backend) — shared API
- [mini-ecommerce-client-portal](https://github.com/II-Fedaa-II/mini-ecommerce-client-portal) — customer-facing storefront
- [mini-ecommerce-infra](https://github.com/II-Fedaa-II/mini-ecommerce-infra) — docker-compose orchestration for all services
